Design and develop a modern, premium cybersecurity-themed web application called HoneyPort Analyzer Simulator. This is a simulation-based educational project, not a real-time security monitoring system. The application should feature a sleek black and neon green (hacker/SOC) theme with glassmorphism, glowing borders, Matrix-style animated background, terminal-inspired UI elements, smooth animations, and a fully responsive layout. Start with an attractive landing page containing a glowing logo, a short description, and buttons for Launch Simulator, Generate Sample Logs, and Upload Log File. The main dashboard should resemble a professional Security Operations Center (SOC), displaying animated statistic cards for Total Logs, Safe Events, Warning Events, Critical Events, Simulated Honeypot Hits, Port Scan Attempts, Brute Force Attempts, and an Overall Security Score. Include a drag-and-drop upload area for .log, .txt, .csv, and .json files, along with buttons to generate realistic simulated datasets such as Normal Activity, Port Scan, SSH Brute Force, Honeypot Interaction, and Mixed Attack scenarios. Display logs in a searchable, filterable, sortable table with columns for Timestamp, Source IP, Destination Port, Service, Event, Detection Rule, Threat Level, and Status. Add interactive data visualizations including a pie chart for security event distribution, a bar chart of targeted ports, a line chart showing simulated attack timelines, and a heatmap representing attack frequency. When a suspicious log is selected, open a detailed analysis panel explaining what happened, why the event was flagged, its simulated risk level, and recommended defensive actions. Include downloadable PDF and CSV security reports with summary statistics and charts. Use realistic cybersecurity icons, loading animations, hover effects, glowing UI components, and dashboard transitions to create a professional enterprise-grade experience. Prominently display a notice stating: "Educational Simulation Only – This application analyzes uploaded or generated sample logs using predefined detection rules. It does not monitor live networks, connect to real honeypots, or detect real-time attacks." The entire application should feel like a polished SOC dashboard used for cybersecurity training, emphasizing visualization, user experience, and educational value rather than live threat detection.
